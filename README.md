# Dashboard de Vendas de assinaturas da plataforma XBox com Excel

## Descrição do Projeto

Este projeto consiste em um dashboard interativo desenvolvido com o Microsoft Excel para análise e visualização de dados de vendas de assinaturas da plataforma XBox. O dashboard permite explorar métricas relacionadas a assinaturas, planos de serviço, preços, renovações automáticas e valores totais, facilitando a tomada de decisões baseada em dados.

O objetivo principal é fornecer uma ferramenta acessível e intuitiva para profissionais de vendas e gestores analisarem o desempenho das assinaturas, identificando tendências, comparando planos e avaliando o impacto de cupons e passes sazonais.

## Dados Utilizados

A base de dados utilizada contém informações sobre assinaturas de usuários, incluindo detalhes como tipo de plano, data de início, renovação automática, preço da assinatura, tipo de assinatura, participação em passes sazonais (EA Play e Minecraft), valores associados e totais.


- **Plan**: Tipo de plano (Ultimate, Core, Standard).
- **Start Date**: Data de início da assinatura.
- **Auto Renewal**: Indica se a renovação é automática (Yes/No).
- **Subscription Price**: Preço da assinatura.
- **Subscription Type**: Tipo de assinatura (Monthly, Annual, Quarterly).
- **EA Play Season Pass**: Participação no passe sazonal EA Play (Yes/No).
- **EA Play Season Pass Price**: Preço do passe EA Play.
- **Minecraft Season Pass**: Participação no passe sazonal Minecraft (Yes/No).
- **Minecraft Season Pass Price**: Preço do passe Minecraft.
- **Coupon Value**: Valor do cupom aplicado.
- **Total Value**: Valor total da assinatura.

Os dados completos estão disponíveis em uma planilha `base` no próprio arquivo.

## Instruções para Reprodução

Para reproduzir e utilizar este projeto, siga os passos abaixo. O dashboard foi desenvolvido no Microsoft Excel e está protegido para evitar modificações acidentais nos artefatos (fórmulas, gráficos e layouts).

### Requisitos
- Microsoft Excel 2016 ou superior (recomendado Excel 365 para melhor compatibilidade com recursos interativos).
- Sistema operacional Windows (compatível com Excel).

### Passos para Execução
1. **Clone ou baixe o repositório**: Faça o download dos arquivos do projeto para o seu computador.
2. **Abra o arquivo Excel**: Localize o arquivo principal do dashboard (geralmente nomeado como `desafio-de-codigo-criando-dashboard-vendas-xbox-excel.xlsx` ou similar) e abra-o no Microsoft Excel.
3. **Navegue pelo dashboard**: Explore os gráficos  e objetos interativos. Use filtros de segmentação analisar os dados conforme necessário.
4. **Proteção da planilha**: A planilha está protegida, mas sem senha, para preservar a integridade dos cálculos e visualizações. Se precisar editar fórmulas ou layouts (não recomendado para uso padrão), desproteja.
   - **Atenção**: Modificações podem alterar o comportamento do dashboard. Faça backup antes de qualquer alteração.

### Dicas de Uso
- Utilize as tabelas dinâmicas e gráficos para filtrar dados por Tipo de assinatura (Monthly, Annual, Quarterly) e os totais das vendas por segmento.
