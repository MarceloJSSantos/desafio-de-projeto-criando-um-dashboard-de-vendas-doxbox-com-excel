## 📋 Descrição do Projeto

Este projeto apresenta um dashboard interativo criado no Microsoft Excel para análise de vendas de assinaturas da plataforma Xbox. O painel permite visualizar métricas essenciais de receita, planos, renovações e adições de passes sazonais, fornecendo insights claros para decisões comerciais.

O objetivo é oferecer uma solução simples e eficaz para gestores e analistas acompanharem o desempenho das assinaturas, compararem planos e avaliarem o impacto de cupons e complementos no valor total.

O desafio foi desenvolvido como parte do **Bootcamp DIO - TOTVS - Fundamentos de Engenharia de Dados e Machine Learning**.

## 🎯 Objetivos Principais
- Visualizar a performance de cada plano de assinatura.
- Analisar renovações automáticas versus manuais.
- Identificar o impacto de cupons e passes (EA Play e Minecraft) sobre a receita.
- Manter o dashboard protegido para evitar alterações acidentais.

## 📊 Dados Utilizados

A fonte de dados é uma base de assinaturas presente no arquivo Excel. Cada linha representa uma assinatura com informações de plano, data de início, preço e valores adicionais.

### Estrutura dos Campos
- **Plan**: Tipo de plano (Ultimate, Core, Standard)
- **Start Date**: Data de início da assinatura
- **Auto Renewal**: Renovação automática (Yes/No)
- **Subscription Price**: Preço da assinatura
- **Subscription Type**: Periodicidade da assinatura (Monthly, Annual, Quarterly)
- **EA Play Season Pass**: Se o cliente possui o passe EA Play
- **EA Play Season Pass Price**: Preço do passe EA Play
- **Minecraft Season Pass**: Se o cliente possui o passe Minecraft
- **Minecraft Season Pass Price**: Preço do passe Minecraft
- **Coupon Value**: Valor do cupom aplicado
- **Total Value**: Valor total faturado

Observação: a planilha está protegida para preservar fórmulas, gráficos e layout.

## 🚀 Como Reproduzir

### Requisitos
- Microsoft Excel 2016 ou superior (Excel 365 recomendado)
- Windows (ambiente compatível com Excel)

### Passos
1. **Clone ou baixe o repositório**.
2. **Abra o arquivo Excel** do dashboard no Microsoft Excel.
3. **Navegue pelas abas** para visualizar gráficos, tabelas e segmentações.
4. **Use os filtros** disponíveis para analisar os dados por plano, tipo de assinatura ou presença de passe sazonal.
5. **Não altere os artefatos produzidos** diretamente, pois a planilha está protegida para evitar mudanças acidentais.

### Proteção do Arquivo
- A planilha está protegida para preservar fórmulas, tabelas dinâmicas e gráficos.
- Caso precise editar algo, faça uma cópia do arquivo antes de desprotegê-lo.

## 💡 Dicas de Uso
- Filtre por **Subscription Type** para comparar mensal, anual e trimestral.
- Utilize as segmentações para verificar tendências por **Plan** e **Auto Renewal**.
